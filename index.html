SBI Data Challenge

Simulation-Based Inference for the next generation of cosmological surveys.

About the Challenge

This data challenge invites participants to develop and benchmark simulation-based inference (SBI) methods on a shared set of problems. The goal is to advance the state of the art in likelihood-free inference for cosmology and astrophysics.

How It Works

  1. Download the data — training simulations and observed summary statistics are provided.
  2. Build your pipeline — use any SBI method you like (NPE, NLE, NRE, ABC, …).
  3. Submit posteriors — sign in with Hugging Face and upload your latest HDF5 file via the submission page.
  4. Compare results — submissions are scored and displayed on a public leaderboard.
